# transcendence

---

## 프로젝트 개요

이 프로젝트는 SPA(Single Page Application) 구조를 이용해 간단한 웹 애플리케이션을 구현하는 것을 목표로 합니다. 프론트엔드는 TypeScript를 사용하며, 백엔드는 Django를 기반으로 구축되었습니다. 이 문서는 프로젝트를 실행하고, 구조를 이해하는 데 필요한 기본적인 정보를 제공합니다.

## 실행 방법

1. **인증서 생성**
   ```bash
   make generate-certs
   ```
   이 명령어를 통해 SSL 인증서를 생성합니다. `.env` 파일의 `DOMAIN_NAME`에 설정된 도메인 이름을 기반으로 인증서가 생성됩니다.

2. **TypeScript 컴파일**
   ```bash
   tsc
   ```
   이 명령어를 통해 TypeScript 코드를 JavaScript로 컴파일합니다. 컴파일된 파일은 `frontend/dist` 디렉토리에 생성됩니다.

3. **프로덕션 환경에서 애플리케이션 실행**
   ```bash
   make build-prod
   make up-prod
   ```
   이 명령어를 통해 프로덕션 환경에서 Docker 컨테이너를 빌드하고 실행합니다.

4. **애플리케이션 접속**
   `.env` 파일에 설정된 `DOMAIN_NAME`을 브라우저 주소창에 입력하여 애플리케이션에 접속할 수 있습니다.

## 프로젝트 구조

- **backend/**: Django 백엔드 파일이 위치한 디렉토리입니다. API 서버와 데이터베이스 연동을 관리합니다.
- **frontend/**: 프론트엔드 파일이 위치한 디렉토리입니다. TypeScript를 이용하여 SPA를 구현하였습니다.
  - **public/**: 정적 파일(CSS, HTML 등)이 위치한 디렉토리입니다.
  - **src/**: TypeScript 소스 파일들이 위치한 디렉토리입니다.
  - **dist/**: TypeScript 컴파일 후 생성된 JavaScript 파일이 위치한 디렉토리입니다.
  - **nginx/**: Nginx 설정 파일이 위치한 디렉토리입니다.
- **docker-compose.dev.yml**: 개발 환경에서 사용할 Docker Compose 설정 파일입니다.
- **docker-compose.prod.yml**: 프로덕션 환경에서 사용할 Docker Compose 설정 파일입니다.
- **Makefile**: 프로젝트 관리 및 실행을 위한 명령어 모음입니다.

## SPA 구조 및 모듈화

이 프로젝트는 SPA 구조를 채택하여, 하나의 HTML 파일 내에서 여러 페이지를 동적으로 렌더링합니다. 라우팅, 페이지 전환, 상태 관리는 모듈화하여 관리합니다.

- **라우팅**: `Router.ts` 파일에서 각 페이지에 대한 라우팅을 정의합니다. URL 경로에 따라 해당 페이지의 컴포넌트를 렌더링합니다.
- **페이지 컴포넌트**: 각 페이지는 독립적인 TypeScript 모듈로 구현되어 있으며, 필요에 따라 CSS 파일을 연결하여 개별 스타일을 적용합니다.
- **CSS 관리**: 전역적으로 적용되는 스타일은 `global.css`에서 관리하며, 페이지별 특화된 스타일은 해당 페이지의 CSS 파일에서 관리합니다.

## 추가 정보

- **확장성**: 프로젝트 구조는 확장성을 염두에 두고 설계되었습니다. 새로운 페이지나 기능을 추가할 때도 일관된 방식으로 쉽게 통합할 수 있습니다.
- **모듈화**: 코드의 재사용성과 유지보수를 고려하여 모듈화를 적극 활용하였습니다. 각 기능은 독립적으로 테스트 및 확장 가능합니다.
